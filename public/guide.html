Guide · what the lab proves

The reasoning is the test.

Each station is one question family from a real front-end assessment brief. The lab's job is not to stump you — it is to make the graded reasoning visible: trace the state, name the assumption, price the trade-off, land on the user.

The stations — first set

Station 1

The var loop

Three timers, one shared binding — the canonical tracing trap.

Proves
You trace what state actually is, not what it should be.
Key detail
let creates a per-iteration binding; var creates one for the whole function.
Station 2

The stale effect

An interval closes over a render snapshot and never sees fresh state.

Proves
Each render is a snapshot — callbacks read the values their render captured.
Key detail
setCount(c => c + 1) reads current state at dispatch; a dep array rebuild works but costs a timer per tick.
Station 3

The 50,000-row table

Memoization cannot save a render that mounts half a million nodes.

Proves
Bound the rendered set first — paginate or virtualize — then optimize within it.
Key detail
React.memo skips re-renders, not the first render; the DOM count is the freeze.
Station 4

fetch that "works"

An HTTP 500 resolves — rejection is reserved for transport failure.

Proves
The error path is the graded path: response.ok, timeouts, retry only what is idempotent.
Key detail
The crash lands three lines away from the cause — on data.rows being undefined.
Station 5

The sorted revenue column

Default sort() compares strings — "10000" before "450".

Proves
Metrics must be believable: sort raw values, format only at display.
Key detail
Intl.NumberFormat formats the view; the comparator sorts the numbers.
Station 6

The div that looks like a button

Pointer users see a button; keyboard users see nothing at all.

Proves
Accessibility is part of the rubric — semantics reach users that styling cannot.
Key detail
tabindex + role + keydown is three patches to fake one <button>.

The stations — second set

Station 7

Microtasks beat timers

console.log, a setTimeout, and a Promise.then walk into an event loop.

Proves
The microtask queue drains completely before the next macrotask runs.
Key detail
a, d, c, b — sync code first, then promises, then timers.
Station 8

The frozen useMemo

A dep array of [] caches the first computation forever.

Proves
Memoization is a contract: every value read inside must appear in the deps.
Key detail
Omitting threshold renders the stale filter — the same stale-closure family as Station 2.
Station 9

The racy search

Two fetches in flight; the slow one resolves last and wins.

Proves
Response order is not request order — cancellation or a staleness guard is structural, not optional.
Key detail
AbortController in the effect's cleanup kills the older request before it can resolve.
Station 10

The off-by-one day

"2026-10-05" parses as UTC midnight — New York is still on Oct 4.

Proves
Calendar dates and instants are different types wearing the same string.
Key detail
Parse date-only values as local (new Date(y, m-1, d)) or keep them strings end to end.
Station 11

The focus that escapes

A div modal opens over a page of links — Tab walks the page behind it.

Proves
Focus is never automatic: move it in on open, trap it while open, restore it on close.
Key detail
<dialog> supplies all three natively — styling is the only real cost.
Station 12

Props vs the snapshot

useState(items) reads the prop once and never again.

Proves
Copying props into state creates two sources of truth that silently diverge.
Key detail
Derive during render, or remount with a new key — never sync with an effect.

The stations — security & types

Station 13

Token in localStorage

A JWT in web storage is one XSS away from a stolen session.

Proves
Every script on the origin can read localStorage — that is the whole blast radius.
Key detail
httpOnly cookies hide from JS but invite CSRF — pick which door to lock, then lock it.
Station 14

The comment that runs

innerHTML on user input is stored XSS with extra steps.

Proves
textContent is free and absolute; markup needs a real sanitizer, never regex.
Key detail
React JSX escapes by default — the vulnerability is reaching for the escape hatch.
Station 15

Index keys slide

Delete row 0 and every surviving row inherits its neighbor's state.

Proves
Keys are identity — the array index is not one.
Key detail
Stateful rows (inputs, expansion) corrupted by index keys produce wrong-record writes.
Station 16

Narrow the union

string | number only shares members both types have.

Proves
typeof narrowing splits the union; any silences the compiler, not the bug.
Key detail
Strict TS turns "expected a number" runtime crashes into compile-time errors.

The stations — tracing & polish

Station 17

The lost this

button.onclick = cart.add detaches the method from its owner.

Proves
this is bound by the call site, not the definition — extracting a method loses the receiver.
Key detail
Arrow wrappers capture the owner; .bind() locks it. The classic "works in console, broken in UI."
Station 18

The in-place sort

rows.sort() mutates the prop array the parent still owns.

Proves
sort() returns the same array — mutation leaked across the component boundary.
Key detail
[...rows].sort() or toSorted() — only mutate what you own.
Station 19

The invisible zero

count ? badge : empty swallows a real 0.

Proves
Falsy is not absent — 0 and "" are values, only null/undefined mean missing.
Key detail
count != null is the check that means what you intend.
Station 20

The silent save

A checkmark appears; the screen reader hears nothing.

Proves
DOM changes are invisible without a live region — aria-live="polite" announces async outcomes.
Key detail
polite waits for a pause; assertive interrupts — reserve it for urgent results.

Assessment-day tips

Timing

Budget the 90 minutes

Skim every scenario in the first five minutes, take the easiest station first, and reserve the last ten for review.

Proves
~15–25 minutes per scenario: 3 to read and trace, 10 to implement, 5 to write the reasoning.
Key detail
The reasoning write-up is graded — never leave it for "if there's time."
Tracing

Narrate, don't nod

Write the trace even when the answer feels obvious — "all three callbacks share one var binding → 3, 3, 3" takes twenty seconds.

Proves
The method is the score; a right answer with no reasoning reads as a guess.
Key detail
Say what each line does to state, not what it "should" do.
Ambiguity

State your assumption

If the scenario doesn't say whether the API paginates or the field can be null, name your assumption and answer under it.

Proves
Ambiguity is deliberate — stating the assumption is itself scored.
Key detail
"Assuming X, I'd do Y because Z" covers assumption, decision, and trade-off in one line.
Review

Bank the last ten minutes

Re-read each answer for the four rubric lines: assumption, options, trade-off, user impact.

Proves
The cheapest points are the rubric lines you forgot to write down.
Key detail
Use this lab's timed run as rehearsal — 20 stations in 90:00, then review the misses.

The rubric card

Frame

Assumption → options → trade-off → user impact

Every answered station reveals the four-part card a senior answer contains.

Proves
Assessments score the reasoning frame, not just the chosen option.
Key detail
Stating an assumption out loud is itself a scored behavior.
Method

Deterministic traces

Run trace replays the same steps every time — the point is inspectability.

Proves
Bug hunting is a procedure: reproduce, isolate, one hypothesis, one change.
Key detail
/api/run returns identical output for identical input — testable end to end.

The API surface

Endpoints

Inspect or drive it yourself

GET /api/scenarios lists stations · GET /api/scenario?id= returns one scenario without its grading key · POST /api/run replays a trace · POST /api/answer scores a choice and returns the rubric. /health and /version report the deploy.

Proves
The lab itself follows the API rules it teaches — explicit error JSON, bounded body size, no hidden state.
Key detail
Grading fields never ship in /api/scenario — they arrive only after you commit.
